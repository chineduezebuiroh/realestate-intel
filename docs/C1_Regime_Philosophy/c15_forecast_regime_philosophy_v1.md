# C1.5 Forecast Regime Philosophy v1

## Purpose

This document defines how forecasted regimes are generated and interpreted.

---

# Core Principle

Forecast Regimes are generated using the same framework as Current Regimes.

There should not be separate classification systems.

---

# Regime Construction

Current Regime:

Current Indicators
→ Scores
→ Coordinates
→ Regime

Forecast Regime:

Forecast Indicators
→ Scores
→ Coordinates
→ Regime

The process is identical.

Only the inputs differ.

---

# Interpretation

Forecast Regimes are directional rather than deterministic.

They represent:

> If forecast assumptions are correct, where would the market likely be positioned within the cycle?

Forecast regimes are therefore scenario-dependent.

---

# Expected Transition Path

The difference between:

* Current Regime
* Forecast Regime

defines the expected transition path.

Examples:

Recovery → Expansion

Expansion → Late Expansion

Late Expansion → Hypersupply

---

# Forecast Horizon Independence

The regime framework should support:

* short-term forecasts
* medium-term forecasts
* long-term forecasts

without modification.

Only forecast inputs change.

---

# Confidence

Forecast confidence should never exceed forecast confidence.

A highly accurate regime classification cannot overcome a weak forecast.

Forecast regime confidence should therefore inherit uncertainty from the forecasting layer.

---

# Design Goal

Users should be able to answer:

* Where is the market today?
* Where is the market likely going?
* How confident should we be?

using a unified framework.

---

# Non-Goal

Forecast Regimes are not predictions of exact future outcomes.

They are structured interpretations of forecasted conditions.
